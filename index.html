01 Professional · 2026 Internal

Backlog Prioritization Engine

A configurable full-stack application that turns a changing operational backlog into a ranked sprint-ready queue. I designed and built the architecture, scoring engine, interface, API, data model, testing, and cloud automation.

Problem

Priorities change as new hardware, workflows, and organizational needs emerge. Static sorting cannot capture that context.

Approach

Score each ticket from 0–100 across five weighted dimensions with reusable profiles that let the team change emphasis without rewriting the algorithm.

Engineering

Built the pipeline from scratch with TypeScript, React, Node.js, Express, NoSQL storage, authenticated cloud hosting, managed scheduling, and Vitest.

Auditability

Persist a complete per-execution scoring breakdown so the ranking is explainable instead of behaving like a black box.

TypeScript / React Node.js / Express NoSQL Vitest Cloud
